# College Teaching Portal Static Website

A simple static website for a college teaching portal, built with HTML and CSS. This site includes multiple pages and navigation links suitable for GitHub Pages hosting.

## Pages Included
- Home
- Login
- Register
- Dashboard
- Student Dashboard
- Teacher Dashboard
- Course Management
- Study Materials
- Assignments
- Quiz & Exam
- Attendance
- Results
- Timetable
- Announcements
- Calendar
- Chat
- Profile
- Admin Panel
- Reports
- Contact

## How to Host on GitHub Pages
1. Commit and push the website files to your GitHub repository.
2. In the repository settings, enable GitHub Pages using the `main` branch and the root folder.
3. After publishing, the website will be available at:
   `https://<username>.github.io/<repository-name>/`

## Example
If your GitHub username is `srishtisonawane2007` and repository is `first-repository`, the Pages URL would be:
`https://srishtisonawane2007.github.io/first-repository/`

## Run locally
Open `index.html` in a browser or use a local static file server.
